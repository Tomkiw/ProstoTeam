## Домовленості

- Кольори, відступи, радіуси — лише змінні з `src/app/globals.css`. Брейкпоінти mobile-first: `@media (min-width: 768px)` і `@media (min-width: 1440px)`.
- Тексти інтерфейсу — у `messages/*.json`. Новий ключ додаємо одразу в **три** файли: TypeScript перевіряє ключі лише за `en.json`.
- Проєкти, команда, послуги, контакти — у `src/data/*.ts`, тексти там одразу трьома мовами.
- Внутрішні посилання — `Link` з `@/i18n/navigation`, не з `next/link`. На секцію — `getSectionHref(SECTION_IDS.<секція>)`.
- Спільні компоненти — `Button`, `Container`, `Logo` з `src/components/ui`. Якщо переданий `className` не перебиває їхній стиль, обгорніть компонент у `div` або підвищте специфічність селектора: порядок CSS-модулів у Next не гарантований.
- Перед PR: `npm run typecheck && npm run lint && npm run format:check`.
