## Домовленості

- Ховери узгоджені: пункти меню — кружечок з лого (`NavList`; у футері ще й підкреслення), кнопки — коло від курсора (`Button`), перемикач мов — при наведенні кругла обвідка, а темна пігулка під активною мовою їде лише після кліку. Для інших посилань — `color: var(--color-link-hover)`; ховер-стилі кладіть у `@media (hover: hover)`.
- Відгук на дотик: на телефоні ховера нема, тож новим посиланням і кнопкам — `:active` (поза `@media (hover: hover)`): посиланням той самий колір, що й при наведенні, кнопки `Button` вже «вдавлюються» самі.
- Темні блоки: на контейнері задайте `--color-link-hover` і `--color-focus` як `var(--color-accent)`, як у `Footer`. Якщо на темному фоні стоїть кнопка — ще `--color-contrast-fill: var(--color-surface)` і `--color-contrast-fill-text: var(--color-text)`, як у `MobileMenu`. Перемикач мов на темному фоні — `<LanguageSwitcher tone="light" />`, як `<Logo tone="light" />`.
- У браузер ідуть не всі переклади, а лише розділи зі `src/i18n/clientMessages.ts`. Додаєте `useTranslations` у клієнтський компонент (`'use client'` або те, що він рендерить) з новим розділом — допишіть розділ туди, інакше в браузері замість тексту буде ключ.
- Списки з класом (`ul`, `ol`) втрачають маркери через скидання в `globals.css` — додавайте їм `role="list"`, інакше Safari з VoiceOver може не оголосити їх як список.
- Кольори, відступи, радіуси — лише змінні з `src/app/globals.css`. Брейкпоінти mobile-first: `@media (min-width: 768px)` — планшет; `@media (min-width: 1024px)` — лише header (десктопне меню, `DESKTOP_MEDIA_QUERY` у `src/lib/constants.ts`); `@media (min-width: 1280px)` — десктоп, тобто макет 1440, який на ноутбуках 1280–1366 стискається (ширини через `fr` і `vw`, а не фіксовані px).
- Тексти з перекладів отримують нерозривні пробіли автоматично (`src/i18n/request.ts`). Текст із `src/data/*.ts` виводьте через `bindShortWords` з `@/lib/typography` — інакше однолітерні слова лишатимуться в кінці рядка.
- Тексти інтерфейсу — у `messages/*.json`. Новий ключ додаємо одразу в **три** файли: TypeScript перевіряє ключі лише за `en.json`.
- Проєкти, команда, послуги, контакти — у `src/data/*.ts`, тексти там одразу трьома мовами.
- Внутрішні посилання — `Link` з `@/i18n/navigation`, не з `next/link`. На секцію — `getSectionHref(SECTION_IDS.<секція>)`.
- Заголовок h2 кожної секції — `<SectionTitle>` з `src/components/ui`, у контактах `<SectionTitle size="lg">` (52px на 1440). Замініть ним `<h2>` у своїх секціях.
- Спільні компоненти — `Button`, `Container`, `Logo` з `src/components/ui`. Якщо переданий `className` не перебиває їхній стиль, обгорніть компонент у `div` або підвищте специфічність селектора: порядок CSS-модулів у Next не гарантований.
- Перед PR: `npm run typecheck && npm run lint && npm run format:check`.

### SEO під час верстки

Технічне SEO вже зроблене (крім JSON-LD) — див. `src/lib/metadata.ts` і `src/lib/site.ts`. А ці звички дорого виправляти потім по всіх секціях, тому — одразу:

- Один `h1` на сторінку — він у Hero. У секціях — `SectionTitle` (h2), у картках усередині секцій — h3. Рівні не пропускаємо.
- Текст — справжнім HTML, не картинкою і не SVG. Чисто декоративне (велике лого в Hero, кружечки) — з `aria-hidden="true"`.
- Зображення — через `next/image` з `alt` трьома мовами (з перекладів) і `sizes`. Декоративні — `alt=""`.
- Посилання — `Link` або `<a href>`, дії — `<button>`. Ніяких `div` з `onClick`: пошуковик не бачить таких переходів.
- Кожна нова сторінка — з `generateMetadata` через `getPageMetadata` з `@/lib/metadata`: title з перекладів, canonical і Open Graph. Якщо сторінка потрібна в пошуку — додайте її шлях у `INDEXED_HREFS` у `src/app/sitemap.ts`.
- Індексація вмикається лише на продакшні з `SITE_URL` (власний домен). Поки змінної нема, сторінки віддають `noindex`, а `robots.txt` — без sitemap.
- Адреси сторінок після запуску не змінюємо. Нові сторінки додаються поруч.

## Дизайн і зрозумілість інтерфейсу

Header, Footer, мобільне меню й перемикач мов — компоненти Ігоря: зміни в них узгоджуємо.

**Правило для всього сайту:** пігулка із заливкою — це кнопка, і тільки вона. Посилання — підкреслені або з іконкою (↗ — для зовнішніх). Мітки й бейджі — пласкі, без заливки-пігулки. Підказка «це клікається» має бути видно без наведення мишею: на телефоні наведення нема.

- [x] Вирішено: хедер видно завжди — без JS і без «стрибків» при прокрутці.
- [x] Кнопка в мобільному хедері: «Написати» / «Napisz» / «Contact» → `#contacts`, з 768 — «Обговорити проєкт». На 320 влазить.
